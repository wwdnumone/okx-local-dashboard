# 使用教程

本教程适用于仓库中的 `index.html`。软件本身不需要安装，查询真实数据时需要可连接 OKX 的网络环境。

## 1. 下载与打开

1. 打开 GitHub 仓库首页。
2. 点击 **Code → Download ZIP**。
3. 解压 ZIP，找到 `index.html`。
4. 使用当前版本的 Chrome、Edge、Safari 或 Firefox 打开文件。
5. 点击 **查看演示**，确认页面可以显示。

不要直接在压缩包预览中打开，也不要将 GitHub 展示的源代码页当成运行页面。手机浏览器能否直接打开本地 HTML 取决于系统；可以使用桌面浏览器完成首次配置。

演示模式不会请求 OKX，展示的金额、价格、订单和账户信息均为示例数据。

## 2. 准备 OKX 只读 API Key

在 OKX 官方网站或应用的 API 管理页面创建 API Key；具体入口可能因地区和版本变化。

1. 选择目标账户或子账户。
2. 权限只勾选 **读取**，不要授予交易或提现权限。
3. 设置并保存 **Passphrase**。
4. 如绑定 IP 白名单，填写实际访问 OKX 时的公网出口 IP。
5. 按 OKX 页面要求完成创建，妥善保存 **API Key、Secret Key、Passphrase**。

模拟盘需要使用模拟盘 API Key；实盘与模拟盘凭证不能混用。网页只能读取该 Key 所属账户及其权限范围内的数据。

## 3. 在网页中配置

如果左侧配置栏已收起，点击左上角的展开箭头；手机端点击 **展开配置**。

| 字段 | 填写说明 |
| --- | --- |
| 备注名 | 便于识别的名称，默认为“交易数据” |
| API Key | 创建 Key 后获得的 apikey |
| Secret Key | 对应的 secretkey |
| Passphrase | 创建 Key 时自己设置的口令；不是登录密码 |
| IP 白名单 | 仅供备注，可留空，不会修改 OKX 白名单 |
| API 地区域名 | 根据账户注册地区选择 |
| 模拟盘 | 使用模拟盘凭证时勾选 |

各密钥字段的 **显示 / 隐藏** 只改变显示方式，不会提交查询。

### 粘贴配置

点击 **粘贴配置**，将以下模板中的内容替换为你的真实信息，再点击 **填入配置**：

```text
apikey = ""
secretkey = ""
passphrase = ""
IP = ""
备注名 = "交易数据"
权限 = "读取"
```

字段使用英文半角等号和引号，一行一个字段。也支持 JSON：

```json
{
  "apikey": "",
  "secretkey": "",
  "passphrase": "",
  "IP": "",
  "备注名": "交易数据",
  "权限": "读取"
}
```

不要把填写真实凭证后的配置提交到 GitHub。模板中的“权限”不会限制 Key 的实际权限，仍需在 OKX 后台正确设置。

### 选择地区

| 账户地区 | 网页选项 |
| --- | --- |
| 全球站 | `www.okx.com` 或 `openapi.okx.com`，按账户地区官方文档选择 |
| 美国 / 澳大利亚 | `us.okx.com` |
| 欧洲经济区 | `eea.okx.com` |

不要仅根据当前所在地选择域名，应按账户所属站点和对应官方 API 文档选择。

## 4. 验证连接

点击 **验证连接**。页面会先获取 OKX 服务器时间，再签名请求交易账户余额。

成功后显示连接状态及账户总权益。此步骤只说明余额读取成功，不代表每种产品均可查询；查询各类数据时仍需满足产品和地区要求。

如果此前查看过演示，点击验证或真实查询后将退出演示模式，不会把演示记录与真实数据混合。

## 5. 查询数据

选择以下标签页，然后点击 **查询数据**：

| 标签页 | 用途 |
| --- | --- |
| 成交明细 | 查看近 3 个月每笔成交，包括部分成交拆分记录 |
| 历史订单 | 查看已结束订单，不等同于每笔成交明细 |
| 当前委托 | 查看尚未完成的委托；本页不提供撤单操作 |
| 当前持仓 | 查看杠杆、永续、交割、期权等持仓；现货余额请看账户资产 |
| 账户资产 | 查看交易账户各币种权益、余额、可用余额等 |

### 产品类型

可选 **所有类型**、SPOT（现货）、SWAP（永续）、FUTURES（交割）、MARGIN（杠杆）、OPTION（期权）、EVENTS（事件）。实际可用产品取决于账户权限。

成交和历史订单在“所有类型”下，会逐类获取数据并合并当前已加载结果。选择 **每类 100 条**，一轮最多获取 600 条，可能需要更长时间。部分类型失败会显示具体类型，不会将部分成功结果标记为全部成功。

### 交易对与币种

- 现货示例：`BTC-USDT`。
- 永续示例：`BTC-USDT-SWAP`。
- 交割和期权请填写账户中实际存在的完整合约代码。
- 账户资产可填写币种，例如 `USDT` 或 `BTC,ETH,USDT`，留空查询全部可返回币种。

“所有类型”的成交及历史订单先获取每类一页，再在本地筛选交易对。因此第一页没有匹配记录时，可以继续加载更早记录，或改选单一类型再查询。

### 时间范围

开始和结束时间按浏览器本地时区输入，页面转换为时间戳发送给 OKX。开始时间不能晚于结束时间。

成交记录按接口记录时间 `ts` 筛选，表格主要显示成交时间 `fillTime`；历史订单按创建时间 `cTime` 筛选。两者含义不同。

时间留空表示查询接口可提供的历史范围，不代表一次加载全部历史。

### 加载更多

单一类型点击 **加载更早记录**；所有类型点击 **加载各类型更早记录**。

各类型使用各自的分页游标，已加载记录按产品类型及记录 ID 去重。全部类型下，表格排序只覆盖已加载数据；各类型尚未加载的旧页中仍可能有比其他类型已加载记录更新的条目。

修改筛选条件后，请重新点击 **查询数据**。部分类型请求失败时，下方加载按钮也可重试失败类型。

## 6. 记住或删除凭证

默认不保存凭证。希望下次自动填入时：

1. 填写完整的三项凭证。
2. 勾选 **记住凭证，下次自动填入**。
3. 确认出现“凭证已保存”的提示，也可点击 **保存配置**。
4. 后续修改凭证时，开启记住功能的页面会自动更新保存。

未勾选记住凭证时，**保存配置**只保存备注名、IP 备注、地区和模拟盘选项。

凭证以未加密形式存储在当前浏览器中，不会写回 HTML 文件。另一浏览器、另一路径、无痕窗口、清除浏览器数据或浏览器的本地文件存储策略变化，都可能导致无法恢复。

| 操作 | 结果 |
| --- | --- |
| 取消勾选“记住凭证” | 删除本地保存的凭证，保留页面当前输入 |
| 点击“清空并忘记” | 删除保存的凭证，清空输入和已加载账户数据 |
| 收起左栏 | 仅隐藏配置，不会断开连接或清空数据 |

如果浏览器禁止删除存储，页面会显示失败提示。可在浏览器设置或开发者工具中清除此文件对应的存储。

## 7. 导出 CSV / JSON

先完成查询，根据需要加载更多，再点击表格右上方的 **导出 CSV** 或 **JSON**。

- CSV：便于在 Excel、WPS、Numbers 等软件中分析，包含当前列表对应记录的原始字段。
- JSON：保留本次已加载的接口响应、数据类型及演示 / 实盘 / 模拟盘标记。
- 导出不包含 API 凭证，但包含个人交易和账户数据，请妥善保管。
- 导出只包含已经获取的数据，不能代替完整账户对账单。
- 长订单 ID 请作为文本导入，避免表格软件自动转换造成精度丢失。

“查看原始响应”可展开检查字段。返回顶部按钮在页面或表格向下滚动后显示，点击后同时返回页面与表格顶部。

## 8. 常见问题

| 现象 | 排查方式 |
| --- | --- |
| 提示缺少 Passphrase | 填写创建 Key 时设置的口令，不是登录密码 |
| 提示 Passphrase 或签名错误 | 核对三项凭证来自同一 API Key，检查复制时的空格与换行 |
| API Key 不存在 / 无效 | 核对账户所属地区、API 域名及 Key 是否仍有效 |
| 实盘 / 模拟盘不匹配 | 使用对应环境的 Key，并核对模拟盘勾选状态 |
| IP 不在白名单内 | 在 OKX 后台核对实际网络出口公网 IP |
| 所有类型中部分失败 | 查看失败类型及提示；产品可能未开通或在该地区不可用 |
| 没有记录 | 检查账户 / 子账户、产品类型、完整交易对、时间范围和分页 |
| 账户权益没有随成交查询更新 | 权益在验证连接或查询账户资产时更新，并非持续实时推送 |
| 记住凭证后仍需填写 | 确认保存成功、使用相同浏览器和文件路径；避免无痕模式 |
| 超时或网络失败 | 检查网络、所选地区域名及接口可达性，稍后重试 |
| 请求过于频繁 | 减少查询频率，等待后重试 |
| CORS / file:// 来源被拒绝 | 这是浏览器与接口的跨域限制，纯 HTML 无法绕过；更换 Key 通常不能解决 |

可打开浏览器开发者工具的 Network / Console 查看网络错误。分享错误时仅提供错误码和脱敏描述，不要分享包含认证头的完整请求、截图或网络日志。

官方接口参考：[OKX API 接入指南](https://www.okx.com/docs-v5/zh/)。
