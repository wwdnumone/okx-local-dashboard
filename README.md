# OKX Local Dashboard · 本地交易数据台

一个基于 OKX API 的单文件交易数据查看工具。在浏览器中配置 API 凭证，即可查询成交、订单、持仓和交易账户资产，并将已加载数据导出为 CSV 或 JSON。

**单文件 HTML · 无需安装 · 无后端 · 只读查询 · 中文界面**

本项目为社区工具，非 OKX 官方产品。页面可直接在本地打开，实际数据请求需要联网，能否读取接口取决于网络、账户地区及 OKX 的跨域策略。

## 功能

| 功能 | 说明 |
| --- | --- |
| 成交明细 | 查询近 3 个月成交记录 |
| 历史订单 | 查询近 3 个月已结束订单 |
| 当前委托 | 查看当前未完成订单 |
| 当前持仓 | 查看杠杆及合约持仓 |
| 交易账户资产 | 按币种查看权益、余额及可用资产 |
| 所有产品类型 | 支持 SPOT、SWAP、FUTURES、MARGIN、OPTION、EVENTS，合并展示已获取的记录 |
| 筛选与分页 | 产品类型、交易对、时间范围、每次条数，支持加载更早记录 |
| 凭证配置 | 手动填写或粘贴配置，可选择记住凭证 |
| 数据导出 | 导出当前已加载数据为 CSV / JSON，查看原始响应 |
| 界面交互 | 可折叠侧栏、记住折叠状态、返回顶部、移动端布局 |
| 演示模式 | 无需 API Key，可预览虚构的交易记录 |

产品是否可用取决于账户权限和所在地区。“所有类型”不会为账户开通未启用的产品。

## 快速开始

1. 在仓库页面点击 **Code → Download ZIP**，解压下载的文件。
2. 使用现代浏览器打开 `index.html`，无需启动服务或安装依赖。
3. 点击右上角 **查看演示**，先预览页面。
4. 在左侧填写 **API Key、Secret Key、Passphrase**，选择正确的地区域名和实盘 / 模拟盘环境。
5. 点击 **验证连接**，再选择标签页、筛选条件并点击 **查询数据**。

完整操作说明见 [使用教程](docs/USAGE.md)。

> GitHub 的 HTML 文件预览展示的是源代码。请先下载并解压，再打开本地 `index.html`。

## API 配置模板

点击页面中的 **粘贴配置**，填入以下格式。也支持使用相同字段名的 JSON 对象。

```text
apikey = ""
secretkey = ""
passphrase = ""
IP = ""
备注名 = "交易数据"
权限 = "读取"
```

- `passphrase` 是创建 API Key 时设置的口令，与账户登录密码不同。
- `IP` 仅为本页备注；真正的 IP 白名单需要在 OKX 后台配置。
- `权限` 是配置说明，不会改变 API Key 的实际权限。请在 OKX 创建仅有 **读取** 权限的 Key。
- 空白模板也提供在 [config.example.txt](config.example.txt) 中。不要将填入真实凭证后的文件提交到仓库。

## 凭证和数据如何保存

默认不保存 API 凭证。勾选 **记住凭证，下次自动填入** 后，凭证会以**未加密形式**存入当前浏览器的 `localStorage`，下次打开相同文件时尝试自动恢复。

取消勾选会删除已保存的凭证，保留当前页面输入。点击 **清空并忘记** 会同时删除本地保存的凭证，清空页面凭证和已加载账户数据。

页面不加载第三方脚本、不使用公共代理、不包含统计埋点。查询请求直接发送至所选的 OKX 官方域名。Secret Key 在本地用于签名，正常请求发送 API Key、Passphrase、签名及时间戳。

浏览器扩展、设备上的其他软件及同来源页面可能影响本地数据安全。请仅在可信设备和可信的 HTML 副本中保存只读凭证。浏览器、文件路径、网站来源或隐私设置变化后，保存信息可能无法恢复。

## 查询范围与分页

- 成交和历史订单使用 OKX 近 3 个月接口，实际保留范围以官方接口为准。
- 单一类型可选择每次获取 20 / 50 / 100 条。
- 成交和历史订单选择 **所有类型** 后，会分别请求各产品类型，按时间倒序合并当前已加载记录。此时数量标签为 **每类条数**；选择 100 时，一轮最多获取 6 类 × 100 条，实际数量取决于接口结果。
- 各类型分别维护分页游标，点击 **加载各类型更早记录** 继续获取。部分类型失败时会显示提示，并保留其他类型已获取的结果。
- 所有类型模式下，成交与历史订单的交易对筛选在已获取结果中进行；第一页没有匹配项时，仍可能需要加载更早记录。
- 当前委托和当前持仓的“所有类型”使用接口原生查询能力。
- 列表数量和导出内容仅覆盖已加载数据，不代表完整历史。未完成加载的结果也不应视为完整历史的全局时间排序。

## 已知限制

1. **跨域限制**：浏览器直连可能被 CORS 或 `file://` 来源策略阻止。纯 HTML 无法绕过服务端跨域策略；本项目不会要求关闭浏览器安全机制或使用公共代理。
2. **资产范围**：账户资产来自交易账户，不包含资金账户，不代表用户在 OKX 的全部资产。
3. **单位差异**：现货数量通常为基础币数量，合约数量通常为张；手续费、盈亏按对应币种解释，不将不同币种直接相加。现货市价委托数量还与 `tgtCcy` 有关。
4. **地区和权限**：域名、模拟盘环境、IP 白名单及产品权限需要与 API Key 匹配。
5. **存储限制**：无痕模式、清除浏览器数据或禁用本地存储，会影响凭证保存。
6. **金额与 ID**：导出保留原始字段值；表格软件自动转换可能改变长 ID 精度，请按文本导入 ID 列。

## 接口与实现

| 数据 | 接口 |
| --- | --- |
| 服务器时间 | `GET /api/v5/public/time` |
| 成交明细 | `GET /api/v5/trade/fills-history` |
| 历史订单 | `GET /api/v5/trade/orders-history-archive` |
| 当前委托 | `GET /api/v5/trade/orders-pending` |
| 当前持仓 | `GET /api/v5/account/positions` |
| 交易账户资产 | `GET /api/v5/account/balance` |

使用浏览器 Web Crypto 完成 HMAC-SHA256 签名和 Base64 编码，并获取 OKX 服务器时间用于签名。应用仅实现读取接口，没有下单、撤单、转账或提现功能。

支持全球 `www.okx.com` / `openapi.okx.com`、美国及澳大利亚 `us.okx.com`、欧洲经济区 `eea.okx.com`。域名要求可能随 OKX 政策变化，请以 [OKX 官方 API 文档](https://www.okx.com/docs-v5/zh/) 和账户所属地区的文档为准。

## 开发与验证

直接编辑 `index.html`，刷新浏览器即可预览；无需打包。运行已有逻辑测试需要 Node.js 18 或更新版本：

```bash
node tests/dashboard.test.cjs
```

测试使用虚构凭证、模拟接口响应和简化 DOM，不会向 OKX 发起真实请求。覆盖签名、凭证保存与删除、多类型合并、独立分页、失败重试、筛选、CSV 转义及返回顶部逻辑。

这些测试不替代真实浏览器布局、浏览器跨域行为及各地区实盘接口验证。真实使用结果可能因账户与网络环境而异。
